Què és?

El Buscamines és un joc de lògica clàssic on l'objectiu és descobrir totes les cel·les d'un tauler sense fer explotar cap mina oculta. Va ser popularitzat per Microsoft als anys 90 i continua sent un dels jocs de lògica més jugats del món.

El tauler està format per una quadrícula de cel·les ocultes. Algunes amaguen mines, la resta són segures. Cada cel·la segura que descobreixes mostra un número que indica quantes mines hi ha entre les cel·les veïnes.

Normes del joc

  1. 👆 Toca qualsevol cel·la per començar.
  2. 🔢 Si la cel·la és segura, apareix un número (1–8) indicant les mines adjacents. Si no n'hi ha cap, s'obre automàticament tota la zona buida.
  3. 🚩 Clic dret per col·locar una bandera on creus que hi ha una mina.
  4. 💣 Si toques una mina — game over!
  5. 🏆 Guanyes quan totes les cel·les segures estan descobertes.

Consells per guanyar

  1. 🎯 Comença pel centre — sol obrir més cel·les d'una vegada.
  2. 🔍 Usa els números — si un "1" ja té una bandera al costat, les altres cel·les veïnes són segures.
  3. 🧠 No marquis a l'atzar — cada bandera ha d'estar justificada per la lògica dels números.
  4. 👀 Mira el context — combina la informació de diversos números per deduir on són les mines.
