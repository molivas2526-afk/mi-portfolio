# Projecte Free

## Descripció

El Projecte Free és una solució integral desenvolupada com a projecte intermodular. Combina el desenvolupament d'un videojoc 2D, la implementació d'un sistema ERP/CRM per a una clínica veterinària, l'ampliació del Football Manager amb automatització de bases de dades, la configuració de servidors i el disseny d'una Landing Page adaptada a mòbils.

L'objectiu principal és aplicar els coneixements adquirits als diversos mòduls per resoldre problemes reals d'empresa, gestionar el programari i demostrar autonomia en la presa de decisions tècniques.

---

## Tecnologies utilitzades

| Tecnologia | Ús en el projecte |
|---|---|
| Java + Swing | Desenvolupament del videojoc 2D |
| SQL (Procediments i Triggers) | Automatització de la base de dades |
| HTML / CSS / JavaScript | Disseny de la Landing Page adaptada a mòbils |
| Dolibarr (ERP/CRM) | Gestió de la clínica veterinària |
| Oracle VirtualBox | Configuració de servidors Linux i Windows |
| GitHub | Control de versions i documentació |

---

## Funcionalitats principals

- **Videojoc 2D** — Desenvolupat amb Java i la llibreria Swing, amb accés a base de dades i control de versions
- **ERP/CRM (Dolibarr)** — Gestió de l'estoc, vendes, clients i agenda de visites d'una clínica veterinària
- **Football Manager ampliat** — Automatització de base de dades mitjançant procediments i triggers SQL, amb diagrames de casos d'ús
- **Landing Page** — Disseny responsive adaptat a mòbils amb HTML, CSS i JavaScript
- **Servidors** — Configuració i administració de servidors Linux i Windows amb VirtualBox
